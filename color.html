アプリへの反映方法

  1. 「色コードをコピー」を押す
  2. アプリの「設定 → テーマ」でカスタムカラーを開く
  3. 「スライダ」タブの「sRGB 16進数カラー値」に貼り付け
  4. 「グラデーションにする」をONにする

「単色」「グラデーションおまかせ」は無料で設定できます。

  1. カスタムカラーで「グラデーションにする」をONにする
  2. グラデーションの詳細設定のバーをタップして、上の「使っている色」と同じ数・同じ位置にツマミを置く
  3. ツマミをタップして選び、「スライダ」タブの「sRGB 16進数カラー値」に色コードを貼り付け
  4. 「方向」で同じ矢印を選ぶ

「グラデーション詳細設定」は Pro版 の機能です。

  1. 「色コードをコピー」を押す
  2. アプリの「設定 → 基本色」を開く
  3. 「貼り付け」をタップすると反映されます
  4. 「グラデーション」はOFFのままにします
  1. アプリの「設定 → 基本色」で「グラデーション」をONにする
  2. バーの丸をタップして選び、左右にドラッグして上の「使っている色」と同じ位置に合わせる
  3. 選んだ丸の色を、コピーした色コードから「貼り付け」で反映する（3色ぶん）
  4. 文字・アイコンの色は「基本色」で別に設定します

マネトーンのグラデーションは無料、向きは上から下のみです。

このページのURLには色が含まれるので、URLを共有すると同じ色・グラデーションを開けます。
